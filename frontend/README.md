# Frontend — Driving License Exam Prep UI

React + TypeScript single-page application providing quiz interface, progress dashboard, and RAG explanation display.

> **Technology:** React 18 + TypeScript + React Query + Tailwind CSS + React Router

## Responsibilities

- User authentication flows
- Quiz interface (practice & exam modes)
- Progress dashboard visualization
- RAG explanation display with citations
- Jurisdiction/language selection
- Responsive desktop-first design

---

**Test Categories:**
- Component tests: Render and interaction
- Hook tests: State and API calls (mocked)
- Integration tests: Full user flows
