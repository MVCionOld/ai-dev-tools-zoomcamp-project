# Frontend Instructions — React + TypeScript

## Stack

React 18+ · TypeScript · Vite · TanStack Query · Zustand · Tailwind · shadcn/ui · React Router

---

## Folder Structure

```
src/
├── modules/           # Feature modules (Auth, Quiz, Dashboard, Explanation, Settings)
├── components/        # Shared UI components
├── hooks/             # Custom React hooks
├── services/api/      # Backend API integration
├── stores/            # Zustand stores
├── types/             # TypeScript definitions
├── utils/             # Helper functions
└── App.tsx
```

---

## Component Pattern

```
components/ComponentName/
├── index.tsx              # Export
├── ComponentName.tsx      # Implementation
├── ComponentName.test.tsx # Tests
└── ComponentName.types.ts # Types
```

---

## State Management

| State Type | Tool | Example |
|------------|------|---------|
| Server data | React Query | Questions, progress, explanations |
| UI state | `useState` | Modal open/closed, form inputs |
| Global client | Zustand | Jurisdiction, language preference |
| URL state | React Router | Quiz ID, page filters |

## TypeScript Rules

- `strict: true` in tsconfig
- No `any` — use `unknown` for external data
- `interface` for objects, discriminated unions for complex state
- Naming: `PascalCase` for types/interfaces, `ComponentNameProps` for props

---

## API Rules

- All calls through `services/api/`
- Never `fetch` directly in components
- Handle loading, error, empty states via React Query

---

## Do Not

- Install packages without approval
- Put business logic in components (use hooks/services)
- Use `any` under any circumstance
- Modify `vite.config.ts` or `tsconfig.json` without discussion
- Use inline styles (use Tailwind)
