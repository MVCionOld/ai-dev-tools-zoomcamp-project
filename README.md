# AI Dev Tools Zoomcamp Project

A Copilot-first full-stack repository bootstrap designed for AI-assisted development.

## Repository Structure

```
.
├── backend/          # Backend service components
├── frontend/         # Frontend application components
├── docs/             # Project documentation
├── .github/          # GitHub configuration and Copilot instructions
├── README.md         # This file
├── ARCHITECTURE.md   # System architecture documentation
└── CONTRIBUTING.md   # Contribution guidelines
```

## Purpose

This repository serves as a bootstrap template for building full-stack applications with GitHub Copilot. It establishes:

- Clear architectural boundaries between frontend and backend
- Documentation standards for all components
- Guidelines for AI-assisted development
- Coding standards and conventions

## Getting Started

1. Review `ARCHITECTURE.md` to understand the system design
2. Read `CONTRIBUTING.md` for development guidelines
3. Check `.github/copilot-instructions.md` for Copilot-specific constraints
4. Explore component-specific READMEs in `frontend/`, `backend/`, and `docs/`

## Development Approach

This is a Copilot-first repository. All development should leverage GitHub Copilot while respecting the architectural constraints and guidelines defined in this repository.

## Documentation

- **ARCHITECTURE.md**: System architecture and design principles
- **CONTRIBUTING.md**: How to contribute to this project
- **frontend/README.md**: Frontend-specific documentation
- **backend/README.md**: Backend-specific documentation
- **docs/README.md**: Documentation guidelines and standards
