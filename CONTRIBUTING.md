# Contributing

## Workflow

1. Read `ARCHITECTURE.md`
2. Check relevant `.instructions.md` (backend or frontend)
3. Implement following patterns
4. Update docs if structure changes
5. Self-review against checklist

---

## Git

**Commits:** Atomic, clear message, reference issues  
**Branches:** `feature/`, `fix/`, `docs/` prefixes

---

## Dependencies

Requires approval. In PR: justify necessity, note alternatives considered.

---

## Structural Changes

Update `ARCHITECTURE.md` and relevant READMEs before merging.

---

## Checklist

- [ ] Follows architectural patterns
- [ ] No unapproved dependencies
- [ ] Docs updated if needed
- [ ] Tests pass
